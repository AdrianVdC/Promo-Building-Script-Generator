# NATS Bonus Creator — v2.34 Changelog

**Release date:** August 25, 2026
**Scope:** DMCA toast title only — the Daily Missions - Canada Playmaker toast title is changed from `Promotion Complete!` to **`Mission Complete!`** per stakeholder direction. Whole-file diff vs v2.33 is **exactly six lines**; `buildDMCAScript` is the only builder changed — **all 11 other builders untouched**. No selector, window, segment, or copy changes beyond the toast title and matching UI notes.

---

## The change

The DMCA Playmaker bonus Step 5 fills `input[name='toastTitle']` with `Mission Complete!` (previously `Promotion Complete!`). Everything else about the toast is unchanged:

- Toast remains **always ON** (`#toastEnabled` checked if not already)
- **CC-day description:** `You have been awarded $X Casino Credit`
- **FS-day description:** `You have been awarded {spins} Bonus Spins to {game_name}` — still no quotes around the game name
- **BG-RE's toast is deliberately untouched** — it still writes `Promotion Complete!` (its own `set_toast` in the test-environment Playmaker template). Change it separately if the same rename is wanted there.

## Exact diff vs v2.33 (six lines)

1. Page `<title>` bumped to v2.34
2. DMCA INFO panel toast note → `"Mission Complete! You have been awarded $X Casino Credit"`
3. FS day-card toast note → `"Mission Complete! You have been awarded {spins} Bonus Spins to {game}"`
4. CC day-card toast note → `"Mission Complete! You have been awarded $X Casino Credit"`
5. DMCA generated-script docstring `Generated by NATS Bonus Creator v2.31` → `v2.34` — a **version-string drift fix**: the docstring had read v2.31 through the v2.32 and v2.33 releases (display-only; same defect class as the `<title>` drift fixed in v2.29 and v2.33)
6. The `toastTitle` fill inside `buildDMCAScript`'s Phase 2 `set_toast`

## Verification (per the template-literal limitation)

- The new string contains no backslashes, backticks, or `${` — **safe by construction** (same class as the v2.29 Matched Deposit insertion).
- The edited line was round-tripped through a real JS template literal (node) and the resulting Python passed `ast.parse`.
- Whole-file diff against v2.33 confirmed to be exactly the six lines above — nothing else moved; `buildDMCAScript` is the only builder whose hash changed.
