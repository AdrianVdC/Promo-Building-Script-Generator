| v2.20 | Aug 9, 2026 | **Casino Game selection made ™-tolerant (RTC FS / RAF / SUO)** — NATS renamed casino games to include a trademark symbol (e.g. `Triple Cash Eruption` → `Triple Cash Eruption™ (WV)`), which broke game selection in all three free-spin flows: scripts typed `{searchName} ({jurisdiction})` into the search box, and the `™` sitting between the name and the jurisdiction suffix caused zero search results, followed by a 15s exact-match timeout. Game selection now works in two parts: **(1) Search** — scripts type only the portion of the search name before any `™` (`Triple Cash Eruption`, `7's Fire Blitz`, `WrestleMania`), surfacing every variant regardless of how NATS renders the symbol; **(2) Match** — the dropdown option is chosen with an anchored regex where every `™` is optional (both mid-name and trailing) but the jurisdiction suffix is required, so the correct state's game is always selected whether or not NATS includes `™`, and wrong jurisdictions or similarly-named games can never match. `parse_casino_game()` replaced by `parse_casino_game_search()` + `parse_casino_game_pattern()` in the RTC FS, RAF, and SUO templates. Terminal output now prints the actual option text NATS displayed (e.g. `Casino Game: Triple Cash Eruption™ (WV)`). The `GAMES` table is unchanged — no search-name edits are needed for the four existing games, and the matcher is resilient if NATS adds or removes `™` again. Matching logic validated against 10 unit tests covering old naming, new naming, wrong-jurisdiction rejection, and similar-name rejection. |
