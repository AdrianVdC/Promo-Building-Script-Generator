STEP 2 — SET YOUR LOCAL FOLDER PATH

The script needs to access images from your computer. Make sure Google Drive for Desktop is installed and the shared folder is synced, then follow these steps:

  1. Open Finder and locate the synced images folder
  2. Right-click the folder → Get Info
  3. Copy the full path shown under "Where:"
  4. Paste it below, then add /[folder name] at the end

This is saved locally to your browser and only needs to be set once.
