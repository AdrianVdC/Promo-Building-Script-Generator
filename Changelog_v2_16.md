| v2.16 | Jul 27, 2026 | New offer type: **Lifecycle - REACT CC Drop** — eighth offer type added to the HTML tool. Day card: 3 days by default, amounts grid shows only `$10`, `$25`, `$50` (all unselected by default), Segment/Promo/Bonus step badges, Send to XP, Days to Opt In / Entitlement / Settlement (all default to 3). Code name format: `MMDDYY_CAS_LC_REACT_{jurisdiction}_CC_{amount}`. Promo window: `00:00:00 ET → 23:59:59 ET +72h`. Bonus activation window: identical to promo window. Voucher code format: `CRLCCC{MMDDYY}{XXX}`. T&C baked in per-amount with per-tier Terms IDs (`CAS_9237` / `CAS_9238` / `CAS_9456`) and per-tier promotional periods. Promo Title and Header Text both read `Get $X in Casino Credit`. Bonus Description: `Get $X in Casino Credit`. Bonus Origin: `Opt-In Bonus`. Series: `Reactivation`. Type: `Lifecycle`. No confirmation modal after Save. Segment dropdown click fixed to use anchored regex scoped to `.ant-select-dropdown:not(.ant-select-dropdown-hidden)` — consistent with Promotion Tile selector pattern. localStorage keys: `lc_react_hiw`, `lc_react_tc`, `lc_react_image_path`. Google Drive images folder: `https://drive.google.com/drive/folders/1Xhk-3fKF3goNS_lL7M0bn2DrACKyFRds`. Generates `lc_react_MMDDYY_HHMM.py`. |
