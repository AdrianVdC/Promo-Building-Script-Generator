Script Generator

Configure dates & amounts — generate a ready-to-run Python script.

  • Editing HIW + T&Cs: Please copy & paste a full version of the HIW or T&Cs, which will be applied to all future versions once saved.
  • Editing Images: Image naming convention is important — make sure all images are PNGs.
    • Masthead Image: There can only be one Masthead image in the folder at a time, and the file name must be Masthead.
    • Promo Detail Image: There can only be one Promo Detail image in the folder at a time, and the file name must be Promo Detail.
    • Discover Image(s): The script looks for the AMOUNT in Google Drive and finds the Discover Image with the matching file name. Script will fail if no image matches the selected AMOUNT.
      • e.g. For a bonus amount of 800, the Discover image must be called 800.

STEP 2 — SET YOUR LOCAL FOLDER PATH

The script needs to access images from your computer. Make sure Google Drive for Desktop is installed and the shared folder is synced, then follow these steps:

  1. Open Finder and locate the synced images folder
  2. Right-click the folder → Get Info
  3. Copy the full path shown under "Where:"
  4. Paste it below, then add /[folder name] at the end

This is saved locally to your browser and only needs to be set once.
